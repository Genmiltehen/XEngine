Единственный источник планов проекта. Выполненные пункты удаляются.

- `# [ Название ]` — раздел плана.
- `## [ Название ]` — подраздел, если нужен.
- `- TODO [<lvl>]: <краткое описание>` — начало задачи. Всё, что идёт ниже до следующего
  `- TODO [<lvl>]:`, относится к этой задаче: несколько абзацев, вложенные списки,
  снипеты кода и другие материалы. Продолжение лучше отделять отступом в 2 пробела.
- `lvl` — уровень критичности: `0` — блокер, `1` — высокий, `2` — средний,
  `3` — низкий, `4` — минимальный.

Пример многострочного TODO:

~~~markdown
# [ Инвентарь ]
- TODO [1]: переписывание логики инвентаря
  Первая строка — краткое описание. Ниже можно расписать полный план.

  ```csharp
  var inventory = new Inventory();
  ```

- TODO [.]: следующий пункт
~~~
